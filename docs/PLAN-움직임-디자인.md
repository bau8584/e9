## 먼저 풀 충돌

`DESIGN.md`가 지금 계획과 부딪힌다. 소유자 승인 뒤 문서를 먼저 고친다.

- 16행 "움직임은 카드 공개와 순위 상승에만": 전체에 움직임을 넣으려면 바꿔야 한다.
- 15행 "그림자, 그라데이션 금지": 금빛이 스쳐 가는 효과는 그라데이션이다. 희귀 카드와 배지에서만 잠깐 허용할지 정한다.

## 원칙

- 강도를 셋으로 나눈다. 평소에는 조용하게, 보상 순간에만 크게.
- 절정은 배지 획득, 희귀 카드, 순위 상승 셋뿐이다.
- 읽기 화면의 본문은 움직이지 않는다. 오답도 흔들지 않는다.
- 저장은 지금처럼 먼저 끝낸다. 연출은 저장 뒤의 표시일 뿐이라, 도중에 창을 닫아도 카드와 점수는 남는다.
- 저장 키와 저장 형식에 새 값을 넣지 않는다.

## 만드는 방법

애니메이션 라이브러리는 넣지 않고 CSS와 브라우저 기본 기능으로 만든다. 필요한 기능이 적고, 단일 파일 `힙독.html`도 그대로 유지된다.

- 규칙 값과 공통 움직임은 `src/styles/global.css`에 둔다. 새 파일로 만들면 입덕 쪽 범위에 묶여 내 방에 닿지 않는다.
- 움직임 이름에는 `hd-`를 붙인다. 이름이 앱 전체에서 공유되기 때문이다.
- 내 방은 `room.css`를 고치지 않고 `src/features/my-room/`에서 덮어쓴다.
- 화면 전환은 들어오는 쪽만 연출한다.
- 움직이는 속성은 위치 변환과 투명도로 제한한다.
- 코드 조각 분리(동적 불러오기)는 쓰지 않는다. 단일 파일 빌드가 깨진다.
- 스크립트로 만든 움직임은 '동작 줄이기' 설정을 따로 확인한다. 기존 CSS 규칙이 막아 주지 못한다.

## 단계

### 1단계: 보상 순간
카드 앞뒤 뒤집기, 희귀 카드 연출, 카드 등급 틀, 실제 순위가 오를 때만 이동, 점수 올라가기, 카드와 순위의 순서 정리.

끝 기준:
- 뒷면을 누르면 뒷면이 돌아가 앞면이 나온다.
- 희귀 카드만 금빛이 난다.
- 순위가 그대로면 줄이 움직이지 않는다.

### 2단계: 화면 흐름
화면 전환, 버튼 눌림, 정답 선택 강조, 새 DM 말풍선 차례로 등장.

끝 기준:
- 메뉴를 옮길 때 끊기는 느낌이 없다.
- 정답을 고르면 그 버튼이 빛난 뒤 넘어간다.
- 읽은 DM을 다시 열면 말풍선이 바로 나온다.

### 3단계: 시작과 소장
배지가 찍히듯 안착, 첫 화면 등장, 새 책만 내려앉기, 빨간 점.

끝 기준:
- 입덕을 끝내면 배지가 찍힌다.
- 책을 등록하면 새 책만 움직인다.

### 4단계: 디자인 정리
인물 그림 채우기와 니체 이미지 경량화, 내 방 최소 글자 12px, 내 방 색과 모서리 맞추기, 읽기 화면을 책 지면처럼, 홈에서 인물을 크게.

끝 기준:
- 375폭 내 방에서 글자가 어려움 없이 읽힌다.
- 첫 화면 네 인물의 그림 수준이 같다.
- 입덕 쪽과 내 방이 한 제품처럼 보인다.

### 마지막 점검
동작 줄이기, 320폭, 저사양 폰, 테스트와 타입 검사.

끝 기준:
- 동작 줄이기를 켜도 모든 내용이 대기 없이 보인다.
- 320폭에서 가로 넘침이 없다.

| 반복하면 지루함 | 절정은 방금 뽑았을 때만 재생. 다시 볼 때는 바로 표시 |
| 내 방 아바타가 끊김 | 위치 지정 방식이라 무거움. 테스트가 이 방식을 읽고 있어 이번 범위에서 뺌. 끊기면 따로 다룸 |
| 테스트 환경에 없는 브라우저 기능 | 있는지 먼저 확인한 뒤 호출 |

## 소유자 결정

1. `DESIGN.md`의 움직임 제한을 푼다. 추천: 푼다.
2. 금빛 효과를 보상 순간에만 허용한다. 추천: 허용.
3. 디자인 방향. 추천: B.
   - A 야간 서재: 전체를 짙은 보라와 금색으로. 비용이 크고 긴 글을 읽을 때 피로하다.
   - B 수집 카드 도감: 크림 바탕을 유지하고 카드와 초상을 주인공으로. 비용은 중간이고 그림 제작이 핵심이다.
   - C 활판 문예지: 글자 중심의 인쇄물 느낌. 품격은 좋지만 팬덤의 설렘이 약하다.
4. 시작 범위. 추천: 1단계만 먼저 만들어 보고 손맛을 확인.

그림체, 주색 유지, 글꼴 최종안, 카드 등급 이름은 4단계 전에 정한다.
