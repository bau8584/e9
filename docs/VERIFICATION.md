# HIP讀 검증 결과

검증일: 2026-11-07, 한국 시간

## 자동 검사

Node 테스트 11개를 통과했습니다.

- 새 개인 서고가 빈 상태이며 학년이 없는지 확인
- 제목·저자·장르·실제 달력 날짜 검증, 선택 입력인 문장·감상 확인
- 닉네임·완독일·문장·감상의 저장 및 복원
- 손상 데이터와 중복 식별자에 대한 원본 보존 및 저장 차단
- 저장소 용량 부족에 대한 실패 반환
- 개인 책의 장르·문장·검색·정렬 및 통계
- 책사이 현재 프로필의 최신 완독 기록만 가져오기와 중복 방지
- 최신 상태가 읽는 중인 책의 가져오기 제외
- 아바타의 바닥 경계 계산
- 니체 저서 3종의 제목·저자·판본 대조, 다른 저자 및 다른 책에 잘못된 표지 연결 방지
- 표지 판본 저장·복원, 참고 도서의 완독 자동 저장 방지, 임의의 외부 표지 URL 거부

TypeScript 검사와 Vite 프로덕션 빌드를 통과했습니다. 이미지와 JS·CSS가 포함된 `힙독.html`을 생성했습니다. 단일 파일 배포를 위해 이미지를 포함하므로 Vite에 큰 JS 청크 경고가 나타납니다.

## 니체 실제 표지 추가 검증

- 이전 `니체 저서 표지 찾기` 채팅의 판본 3종을 확인했습니다. 한국어판 2종과 영문판 1종을 구분해 표시합니다.
- 《차라투스트라는 이렇게 말했다》, 《도덕의 계보학》, 《선악의 저편 (영문판)》 표지의 브라우저 로딩을 확인했습니다.
- 영문판은 동일 ISBN 9780141902630의 Penguin 공식 평면 표지를 사용해 불필요한 이미지 여백을 줄였습니다. 원본 이미지를 잘라내거나 생성 이미지로 재현하지 않았습니다.
- 참고 도서의 표지·제목·저자·장르가 등록 화면에 자동으로 반영되는 것을 확인했습니다.
- 실제 완독일은 빈 필수 입력으로 시작합니다. 날짜를 입력하지 않은 저장 시도는 차단되고 기존 개인 기록은 유지됩니다.
- 서고 상세에 출판사·언어 판본·출처 링크가 표시되는 것을 확인했습니다.
- 390×844 모바일에서 표지 3종이 로딩되고 가로로 넘치지 않는 것을 확인했습니다. 문서 너비는 375px이며 각 표지의 오른쪽 끝은 356px 이하입니다.
- 추가 화면은 `desktop-nietzsche-covers-preview.jpg`, `mobile-nietzsche-covers-preview.jpg`입니다.
- 새 배포 ZIP은 `outputs/힙독_개인서고_니체표지.zip`이며 앞서 배포한 ZIP은 보존합니다.

## 검증 한계

- 실제 iOS Safari·Android 기기에서는 확인하지 않았습니다.
- 단일 HTML은 빌드·번들 포함 여부를 확인했고, 주요 상호작용은 개발 서버에서 검증했습니다. `file://` 직접 실행의 저장 정책은 브라우저마다 다를 수 있습니다.
- 손상 데이터·저장 공간 부족은 모듈 테스트로 검증했습니다. 실제 저장 공간을 고갈시키지는 않았습니다.
- 실제 AI 대화·팬클럽 서버·실시간 순위·계정·기기 간 공유는 이 버전의 구현 범위에 포함되지 않습니다.
- 작업 루트는 Git 저장소가 아니며, 원본 책사이 저장소에 이미 스테이징된 파일들이 있어 원본 저장소를 변경하거나 그 변경을 커밋하지 않았습니다.
