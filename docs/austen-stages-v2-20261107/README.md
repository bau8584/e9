# 제인 오스틴 초상 v2

기존 4단계 그림의 자세와 표정이 비슷하다는 피드백에 따라, [6포즈 캐릭터시트](../../public/images/jane-austen-character-sheet.png)를 기준으로 4장을 내장 image_gen으로 다시 생성했습니다.

| 단계 | 구분되는 장면 | 감정 |
|---|---|---|
| 0 | 서서 책을 들고 뺨에 손가락을 댐 | 경계하며 상대를 관찰 |
| 1 | 책상 앞으로 몸을 기울이고 깃펜으로 집필 | 장난기 있는 도전과 관심 |
| 2 | 안락의자에서 독자의 편지를 읽음 | 뜻밖의 감동과 놀람 |
| 3 | 부채를 들고 숄이 움직이는 자세 | 친구 앞에서 편안하게 활짝 웃음 |

캐릭터시트의 올린 갈색 곱슬머리, 남색 재킷, 크림색 드레스, 푸른 리본·숄을 반영했습니다. 4장의 얼굴과 의상은 유지하면서 실루엣·몸의 방향·시선·손·소품을 바꿨습니다.

`public/images/portrait-austen.png`와 `portrait-austen-stage1.png`부터 `stage3.png`까지 교체했습니다. 이전 제작 기록은 `docs/illustrations-20261107/`와 Git 이력에 남아 있습니다.

- [새 4단계 비교](preview.jpg)
- [최종 프롬프트](prompts.md)
- [규격·SHA-256 검증](verification.json)

앱용 PNG는 모두 800×1000입니다. 원본과 축소본을 보며 얼굴·의상 연결, 단계별 자세·표정 차이, 종이와 책의 문자·서명 유무를 육안으로 확인했습니다. 기존 문장 카드와 다른 인물 그림은 변경하지 않았습니다.

반영 후 `npm test`의 93개 테스트와 `npm run build`가 통과했습니다. 빌드 결과의 오스틴 PNG 4장도 제작본과 SHA-256이 일치합니다. 기존 JavaScript 청크 크기 경고는 남아 있습니다.
