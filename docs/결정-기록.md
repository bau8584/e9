# 첫 버전에서 임시로 정한 것

소유자에게 물을 수 없어 합리적으로 정했다. 팀이 언제든 바꿀 수 있다.

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 싯다르타가 누구인가 | 헤세 소설 주인공이 아니라 역사적 붓다(고타마 싯다르타) | PRD에 "신앙 대상"이라는 언급이 있음 |
| 뽑기 결과 (2026-11-07 변경) | 인물당 미션 2개. 첫 미션은 일반, 둘째 미션은 희귀로 고정. 카드 뒤집기 연출은 유지. 확률 뽑기(일반 70%, 희귀 30%)는 없앰 | 운에 따라 못 얻는 카드가 없어야 수집과 재방문 이유가 생김 |
| 다음 미션 여는 때 | 미션을 끝내고 홈이나 DM으로 가면 다음 DM이 열림. 마지막 미션 뒤에는 "이번 시즌 완료" | 관리할 일 없이 흐름만으로 이어짐 |
| 옛 진행 기록 | 저장 키와 형식은 그대로 두고 미션 순서 값만 더함. 값이 없으면 첫 미션. 옛 뽑기로 희귀를 먼저 받은 사람은 카드와 점수를 그대로 두고, 둘째 미션에서 일반 카드를 받음 | 기존 기록을 깨지 않으면서 누구나 2장을 모으고 총 40점이 되게 함 |
| 순위 | 고른 최애가 2위에서 시작해 +20점으로 1위가 되도록 최애별 예시 점수표를 둠 | 어느 인물을 골라도 순위 변화가 보이게. "예시 점수" 표시. `src/data/ranking.ts` |
| 최애 바꾸기 | 입덕 뒤에는 바꾸는 화면이 없음. 내 방 초기화로 다시 시작 | 범위 최소화 |
| 입덕 가능한 인물 (2026-11-07 소유자 결정) | 첫 화면은 다양한 작가 목록을 보여 주고, 실제 입덕은 니체와 순자만 연다. 싯다르타와 오스틴은 준비 중 목록으로 옮기되 이미 고른 사용자의 기록과 콘텐츠는 유지 | 인물 폭은 넓게 보여 주되 만드는 양은 둘로 줄임. `src/data/catalog.ts` |
| 저장 실패 시 | 화면에 기록은 유지하고 상단에 안내와 다시 시도 버튼. 진행은 막지 않음 | 시연 중 멈추지 않게 |
| 제목 글꼴 | Noto Serif KR을 앱에 내장 | 외부 연결 없음 원칙을 지키면서 휴대폰에도 명조가 나오게. 글꼴 이름은 PRD에서 [확인 필요] |
| 초기화 버튼 | 내 방 카드 구역 아래에 있음. 확인 창을 거쳐 입덕 진행(닉네임, 최애, 미션, 카드, 점수)만 서버 사본까지 지우고 서고는 남김. 팬덤 집계 점수와 claims는 남겨 재입덕 때 중복 적립을 막음 | 서고는 사용자의 독서 기록이라 함께 지우면 안 되고, 팬덤 점수를 되돌리면 집계가 어긋남 |
| 담당자 표기 | 코드와 문서에서 실명 대신 "내 방 담당"으로 씀 | 소유자 결정 전 임시 표기 |
| 단일 파일 힙독.html | file:// 로 열면 Firebase를 아예 시도하지 않고 로컬로만 동작, 순위는 "예시 점수" | 파일 주소에서는 인증이 불안정해 결과를 하나로 고정 |
| 팬덤 문서의 lastMissionId | 점수 외에 마지막 미션 번호 한 칸을 둠 | 규칙이 "이번에 함께 만든 claim"을 찾을 길이 이 값뿐. 닉네임이나 사용자 값은 아님 |
| 서고 동기화 한도 | 문서 하나에 200권까지. 넘으면 서버 동기화만 실패하고 기기 기록은 그대로 | Firestore 문서 1MB 제한 |
| 호감도 (2026-11-07 소유자 결정) | 책을 읽고 쌓은 독서 활동으로 오름. 책 등록, 문장(5자 이상), 감상(10자 이상), 미션 완료가 각 1개. 3, 6, 10개에 단계 상승. 책을 지워도 본 단계 아래로 안 내려감. 홈에 지금 관계와 남은 활동 표시. 기준값은 `src/store/bond.ts` | 호감작이 곧 독서가 되게 함. 자기 기록으로 계산해 콘텐츠를 계속 채울 필요가 없음. 거짓 기록은 막지 못하므로 순위나 상품과 연결하지 않음 |
| 호감도와 대화 도전 (2026-11-07 소유자 결정) | 관계 단계는 독서 활동으로만 오름. 대화 속 도전은 단계를 올리지 않고, 열린 단계의 장면을 보는 재미로 둠. 도전 기능은 아직 없음 | 기준이 둘이면 사용자가 무엇을 해야 오르는지 헷갈림 |
| 첫 화면 문구, DM 문구 | 제작진 초안 | 브랜드 문구는 팀이 최종 확정 |

# 2026-11-10 소유자 결정 (사용성 점검 뒤)

자세한 내용과 순서는 `docs/PLAN-덕질-개편.md`.

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 큰 방향 | 인물의 모에화, 미연시와 덕질의 몰입을 적극 쓴다. 학습 독서 앱처럼 보이는 구조(지문 뒤 정답 맞히기, 진도)는 쓰지 않는다 | 출판사는 책 마케팅, 팀은 바이럴이 목표. 공부 앱은 자랑할 이유가 없음 |
| 독서 MBTI | 보조 수단으로 내린다. 자동으로 뜨지 않고, 첫 화면은 인물 선택이 먼저. 홈에서는 뺀다 | 인물 선택과 겹침. 16유형 결과도 결국 두 인물로만 이어짐 |
| 읽기와 DM | 둘 다 언제든 열린다. 읽기 끝에서 그 대목으로 대화하러 가고, DM에서 인물이 읽을 대목을 권하는 다리만 둔다 | DM에 답해야 읽기가 열리는 잠금 때문에 미션 2개 뒤 할 일이 없었음 |
| 읽을거리 | 프로토타입은 3~4권을 일부만 싣는다. 후보: 차라투스트라(서문), 우상의 황혼(잠언과 화살), 순자 권학, 순자 성악. 한 장 5~10분. 출판사 계약 뒤에는 출판사 번역본 맛보기로 바꾼다 | 지금은 한 편 10초 분량. 책 전체 무료 제공은 출판사가 팔 것이 없어짐 |
| 읽기 문제 | 정답 맞히기를 없애고 인물이 "넌 어떻게 생각해?"로 묻는 선택지로 바꾼다. 정답은 없고 답에 따라 반응이 달라진다 | 시험처럼 보이면 안 됨 |
| 카드 (11-07 "확률 뽑기 없앰"을 뒤집음) | 인물 그림 카드 한 종류로 합친다. 읽기나 대화를 마치면 팩을 받고 무작위로 나온다. 등급을 두고, 겹친 카드는 조각으로 바꿔 원하는 카드와 교환한다. 호감도 단계 장면은 한정 카드로 같은 앨범에 넣는다. 무제한 뽑기 버튼과 책 등록 카드팩은 없앤다. 이미 모은 카드는 지우지 않는다. 확률은 화면에 적는다 | 세 종류가 설계 없이 따로 얹혀 구별이 안 됐음. 희소성이 있어야 자랑하고 싶어짐 |
| 호감도 (11-07 "대화로는 안 오름"을 뒤집음) | 난도는 중간(끝 단계까지 2~3주). 읽은 양이 아니라 인물과 보낸 시간과 선택으로 오른다. 읽기는 크게 오르는 이벤트. 첫 단계 상승은 첫날 10분 안에. 나중에 SNS 활동 점수는 하루 상한이 있는 보너스로만 끼운다 | 책 1권 등록으로 1분 만에 오르던 것을 막고, 미연시의 공략 느낌을 냄 |
| 모에화 대상 | 고전 인물로 한정 권고(소유자 확정 전). 근현대 작가는 유족과 권리 문제 | 준비 중 목록에 박경리, 보부아르, 보르헤스가 있음 |
| 자유대화 | 선택 대화는 기본(무제한), 자유대화는 벌어서 쓰는 "대화 시간". 대목 하나를 읽거나 선택 대화 한 편을 끝내면 1회, 최대 3회까지 모음. 한 번은 내 말 8~15번(호감이 높을수록 길다). 입덕 직후 1회는 그냥 줌. 끝나면 인물이 한 줄로 기억하고 팩 1개 | 귀해야 사건이 되고, 이야기는 선택 대화가 끌고 가며, AI 비용이 줄어듦 |
