# 니체 포토카드 40종 기획 초안

상태: 기획 후보. 사용자가 제공한 「Friedrich Wilhelm Nietzsche ver3」의 네 페르소나와 타임락을 반영했다. 아래는 확정 인용문이 아니라 각 카드의 탐색 방향이다. 원문, 정확한 절·날짜, 번역, 맥락은 대조와 사람 검수 후 입력한다. 제목과 답장 예시는 창작이다. 적합한 원문을 찾지 못하면 카드를 수정하거나 교체한다. 1877년 항목은 특히 날짜가 확인된 편지·유고의 검증이 필요하며 주제와 문헌의 연결을 아직 확정하지 않았다.

## 공통 데이터

- 카드 ID, 시기, 기준 시점, 제목, 대화 맥락, 원전 후보, 정확한 위치와 링크
- 독일어 원문, 한국어 번역, 번역자, 작품 내 맥락과 쉬운 설명
- 창작 핵심 답장 예시 및 생성 지침, 이미지 제작 메모, 검수 상태
- 대화에 잘 맞는 근거가 없으면 원문을 억지로 연결하지 않는다. 생성 답장과 실제 인용을 분리한다.
- ver3의 연령 매칭은 선택 가능한 추천 설계안으로 기록하며, 사용자의 직접 선택을 우선한다. 연령만으로 고민이나 적합성을 단정하지 않는다.
- 모델이 대화 종료 시 주제·정서·맥락을 살펴 검수된 카드에서 고른다. 실제 날짜가 기준 시점 이전인 자료만 검색하고, 답장만 대화별로 창작한다. 해당 근거가 없으면 원문 없는 기념 카드로 대체한다.
- 위험 신호가 있는 대화에는 카드 추천이나 역할극보다 안전과 현실의 도움을 우선한다. 고통을 성장의 필수 조건으로 포장하지 않는다.

## 구현 전 검수

1. 각 후보의 실제 독일어 원문을 비판판이나 신뢰할 수 있는 1차 자료와 대조하고, 절·작성일·판본·URL을 기록한다.
2. 발언자와 문맥을 확인한다. 차라투스트라의 등장인물 대사를 역사적 니체의 직접 발언으로 표기하지 않는다.
3. 한국어 번역을 작성·검수하고 사용 권한을 확인한다. 후대 번역을 무단으로 복사하지 않는다.
4. 대화용 답장과 문장 해설이 원문의 의미를 왜곡하지 않는지 검토한다. 1877년 후보에 근거가 없으면 같은 시기의 검증된 자료로 대체한다.
5. 성격·음식·여행 등 일화와 이미지는 별도로 출처·시점·권리를 검토한다.

참고: [Nietzsche Source 디지털 비판판](https://doc.nietzschesource.org/en/ekgwb), [니체의 생애와 작품](https://plato.stanford.edu/entries/nietzsche-life-works/), [1888년 저작 연표](https://assets.cambridge.org/97805216/91635/frontmatter/9780521691635_frontmatter.pdf).

ver3 적용 주의: 1872년의 니체는 생일 전 27세, 생일 후 28세이며 1877년에는 32~33세다. 기준 연도가 같아도 집필·출판 시점과 사건의 월을 확인한다. 특히 1888년 가을의 『이 사람을 보라』는 집필 전 시점에 사용할 수 없다. 원본의 소렌토 체류, 구술, 음식과 일상 관련 세부 묘사는 개별 출처 및 날짜 확인 전까지 확정하지 않는다.
