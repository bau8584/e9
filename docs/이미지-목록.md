# 필요한 이미지 목록

이미지 팀이 ChatGPT로 만든다. 아래 이름 그대로 `public/images/` 폴더에 넣으면 새로고침만으로 자동 교체된다. 파일이 없으면 보라색 자리 표시가 나오니, 일부만 넣어도 앱은 멈추지 않는다.

공통 규칙: PNG 형식. 파일 이름은 영어 소문자 그대로. 그림 안에 글자를 넣지 않는다(문장은 앱이 얹는다). 인터넷에서 받은 이미지를 쓰지 않는다. 생존 작가의 화풍을 지정하지 않는다.
