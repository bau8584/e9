# 힙독 이미지 프롬프트

대상: 이미지 팀. 확인일 2026-11-07. 파일명과 위치는 `docs/이미지-목록.md`가 아니라 실제 코드 기준이다.

## 쓰는 법

1. 아래 칸의 영어 프롬프트를 통째로 ChatGPT에 붙인다. 칸마다 공통 규칙이 이미 들어 있다.
2. 같은 화풍을 맞추려면 `src/assets/nietzsche.png`를 첨부하고 "이 그림의 화풍만 참고하고 인물은 따라 하지 말 것"을 덧붙인다.
3. 지정한 크기가 그대로 안 나오면 가장 가까운 비율로 받아 줄인다. 앱이 잘라 맞추므로 약간 달라도 멈추지 않는다.
4. PNG로, 아래 파일명 그대로(영어 소문자) 저장한다.
5. 글자처럼 보이는 것이 섞였거나 실제 사진처럼 나오면 다시 만든다.

## 코드와 문서가 어긋난 곳

| 항목 | 문서 내용 | 실제 코드 | 팀이 할 일 |
|---|---|---|---|
| 니체 대표 그림 | `public/images/portrait-nietzsche.png`에 넣으면 교체 | `src/components/Portrait.tsx`가 `src/assets/nietzsche.png`를 먼저 쓴다. public 쪽 파일은 무시된다 | 바꾸려면 `src/assets/nietzsche.png`를 덮어쓰고 다시 빌드 |
| 니체 그림 크기 | 800 x 1000 세로 | 현재 파일은 1672 x 941 가로. ASSETS.md 프롬프트도 16:9 | 새로 만들면 아래 2번 프롬프트 사용 |
| "새로고침만으로 교체" | 모든 파일 | `public/images`의 11장은 개발 서버에서 해당한다. 단일 파일 `힙독.html`에는 이 폴더가 포함되지 않고 옆의 `images/` 폴더를 찾는다(코드로 확인, 실행 시험은 안 함) | `힙독.html`로 나눌 때는 `images/` 폴더를 함께 둔다 |
| 희귀 카드 금색 장식 | 그림에 금색 장식을 더한다 | 앱이 희귀 카드에 금색 테두리를 이미 그린다 | 그림 안에 테두리를 그리지 않고 빛과 장식만 넣는다 |
| 카드 잘림 | 세로 120px 띠 | 폭 최대 320px, 높이 120px. 960 x 400은 위아래가 합쳐 10% 정도 잘린다 | 소재를 가운데 80% 높이 안에 둔다 |
| 초상 잘림 | "얼굴을 가운데 위쪽" | 첫 화면 폭 96px, 홈 폭 112px의 세로 띠와 52px, 112px 원으로 표시. 그림 위치 값(가로 82%, 세로 20%)이 모든 인물에 함께 적용되어 세로 띠에서는 오른쪽 부분이 보인다 | 얼굴을 높이 35%, 가운데에서 살짝 오른쪽에 둔다 |
