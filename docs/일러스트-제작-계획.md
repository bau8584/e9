## 현재 상태 (2026-11-07)

**23장 모두 제작되어 `public/images/`에 들어가 있습니다. 새로 나눠 맡을 그림은 없습니다.** 아래 담당과 순서, 프롬프트는 그림을 다시 만들 때 쓰는 참고 자료입니다. 지금 입덕할 수 있는 인물은 니체와 순자이므로, 다시 그린다면 이 두 인물부터 합니다.

## 왜 그리나

사용자가 책을 읽고 기록할수록 최애와 가까워집니다. 그림과 말투가 함께 달라지므로, 같은 사람의 표정과 태도가 단계마다 분명히 달라야 합니다.

| 단계 | 오르는 때 (독서 활동) | 관계의 느낌 |
|---|---|---|
| 0 | 입덕 | 거리감, 시험 |
| 1 | 3개 | 인정 |
| 2 | 6개 | 빈틈을 보여 줌 |
| 3 | 10개 | 내 사람 취급 |

## 맡을 일

담당 이름은 정해지면 적습니다. 같은 인물은 한 사람이 끝까지 맡아야 얼굴이 유지됩니다.

| 묶음 | 담당 | 인물 | 만들 그림 | 장수 |
|---|---|---|---|---|
| 1 | A | 싯다르타 | 기본 + 단계 1, 2, 3 | 4 |
| 2 | B | 제인 오스틴 | 기본 + 단계 1, 2, 3 | 4 |
| 3 | C | 니체 | 단계 1, 2, 3 (기본은 있음) | 3 |
| 4 | D | 순자 | 기본 + 단계 1, 2, 3 (지금 그림은 임시) | 4 |
| 5 | E | 문장 카드 | 인물별 일반, 희귀 | 8 |

합계 23장.

## 진행 순서

1. **기본 그림 먼저.** 싯다르타, 오스틴, 순자의 기본 그림을 만들어 니체와 나란히 놓고 화풍을 맞춥니다.
2. **소유자 승인.** 승인 전에 단계 그림을 만들지 않습니다. 얼굴이 바뀌면 전부 다시 그려야 합니다.
3. **단계 그림.** 승인된 기본 그림을 첨부해 만듭니다. 니체는 1번과 함께 시작해도 됩니다.
4. **문장 카드 8장.** 얼굴이 없어 언제 시작해도 됩니다.
5. **넣고 확인.** 아래 '넣는 곳'과 '합격 기준'을 따릅니다.

## 만드는 법

1. ChatGPT에 **새 대화**를 엽니다.
2. 각 칸의 '첨부' 파일을 올립니다.
3. 프롬프트 칸 전체를 붙여 넣습니다.
4. 표시된 파일명 그대로, PNG로 저장합니다.

## 넣는 곳

전부 `public/images/`에 넣습니다. 파일이 없으면 앱은 기본 그림을 보여 주므로 일부만 넣어도 괜찮습니다. 순자의 임시 그림 4장은 같은 이름의 새 그림으로 덮어씁니다.

## 합격 기준

- 단계 4장을 나란히 놓았을 때 같은 사람으로 보인다.
- 작게 줄여도 표정 차이가 보인다.
- 얼굴이 위쪽 가운데에 있어 좁게 잘려도 남는다.
- 글자, 서명, 로고처럼 보이는 것이 없다. 책과 죽간은 비어 있다.
- 실제 사진 같지 않다.
- 싯다르타가 가볍거나 신앙 대상처럼 보이지 않는다.
- 니체에게 병든 모습이 없다.
- 연애나 성적인 느낌이 없다.
