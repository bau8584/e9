# 콘텐츠 검수표

앱의 원문, 출처, 번역은 전부 **제작진 기억으로 적은 초안**이며 아직 아무것도 확인하지 않았다. 앱에도 "검수 필요"로 표시되어 있다. 확인이 끝나면 아래 칸을 채우고, 표시를 빼는 일은 제출 전에 팀이 함께 정한다.

원문을 고칠 곳: `src/data/readings.ts`, `src/data/cards.ts`

## 공통 원칙

- 원문은 책 이름과 판본 또는 쪽수까지 적는다.
- 번역문은 권리를 확인했거나 공개 이용이 허락된 자료만 쓴다. 지금 들어 있는 번역은 제작진 임시 번역이다. 시중 번역서를 그대로 옮기지 않는다.
- 원문 자체의 저작권이 끝났어도 현대 편집본과 번역본에는 권리가 있을 수 있다.

인물의 실제 발언이 아니다. 앱에 "제작진 각색"으로 표시된다. 고칠 곳: `src/data/dms.ts`, `src/data/characters.ts`

| 인물 | 확인할 것 | 확인자 | 결과 |

| 제인 오스틴 | 비꼬는 말투가 연애 이야기에만 치우치지 않는지 | | 미확인 |

## 인물 생애 사실

현재 앱에는 영문 표기 외의 생애 정보가 없다. 영문 이름 표기만 확인한다. 생애 소개를 추가하면 이 표에 출처 칸을 더한다.

## 순위

순위 숫자는 지어낸 "예시 점수"이며 앱에도 그렇게 표시된다. 실제 집계로 소개하지 않는다.
