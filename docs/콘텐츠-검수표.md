# 콘텐츠 검수표

앱의 원문과 출처는 공개 원문과 **AI 대조를 마쳤고 사람 확인을 기다린다.** 근거와 확인 실패 항목은 [콘텐츠-검수-결과.md](콘텐츠-검수-결과.md)에 있다. 한국어는 모두 제작진 초벌 번역이며, 앱의 "검수 필요" 표시는 사람이 확인할 때까지 유지한다. 표시를 빼는 일은 제출 전에 팀이 함께 정한다.

원문을 고칠 곳: `src/data/readings.ts`, `src/data/cards.ts`

## 공통 원칙

- 원문은 책 이름과 판본까지 적는다. 오스틴은 쪽수를 확인하지 못했으므로 권과 장까지만 적는다.
- 번역문은 권리를 확인했거나 공개 이용이 허락된 자료만 쓴다. 지금 들어 있는 번역은 제작진 초벌 번역이다. 시중 번역서를 그대로 옮기지 않는다.
- 원문 자체의 저작권이 끝났어도 현대 편집본과 번역본에는 권리가 있을 수 있다.
- 결과 칸의 "AI 대조 완료, 사람 확인 대기"는 사람의 최종 확인이 아니다. 확인자 칸은 팀이 채운다.

## 인물 생애 사실

현재 앱에는 영문 표기 외의 생애 정보가 없다. 영문 이름 표기 네 개는 AI 대조 완료, 사람 확인 대기. 생애 소개를 추가하면 이 표에 출처 칸을 더한다. [생애 표기 판정](콘텐츠-검수-결과.md#생애-사실과-영문-표기)

## 순위

순위 숫자는 지어낸 "예시 점수"이며 앱에도 그렇게 표시된다. 실제 집계로 소개하지 않는다.
