# 출판사 표지 권리 검토

확인일: 2026-11-07

**법률 판단이 아니다.** 공개 자료로 위험을 정리한 일반 정보다. 실제 판단은 한국저작권위원회 상담(1800-5455, 위원회 만료저작물 안내 페이지 기재 번호)이나 변호사에게 받는다.

## 결론

- 추천: **색 표지로 바꾼다.** 앱에 이미 만들어진 화면이 있어 관리자가 할 일이 없고, 허락을 기다릴 필요도 없다.
- 니체의 원작 권리가 끝났어도, 표지 디자인과 표지에 쓰인 그림의 권리는 따로 볼 문제다.
- 표지는 **이미 공개 상태다.** 공개 GitHub 저장소 `bau8584/e9`의 `main`에 올라가 있다. 바꾼다면 앞으로 넣지 않는 일과 과거 기록을 지우는 일을 나누어 정해야 한다.

## 무엇이 위험한가

| 위험 | 왜 그런가 |
|---|---|
| 복제와 공개 | 파일을 앱에 보관하는 것(복제)과 누구나 보게 하는 것(공개)이 함께 일어난다. 링크만 거는 경우와 사정이 다를 수 있다 |
| 권리자가 여럿일 수 있음 | 출판사, 표지 디자이너, 표지에 쓰인 그림이나 사진의 권리자가 따로일 수 있다. Penguin 안내도 다른 출처가 표기된 이미지는 그 출처에 문의하라고 한다 |
| 판매처 이미지는 허락이 아님 | YES24, 교보문고, Apple Books에 올라와 있다는 것이 다른 앱에서 써도 된다는 뜻은 아니다 |
| 출처 표시는 허락이 아님 | ASSETS.md와 앱의 출처 표기는 좋은 습관이지만 허락을 대신한다고 볼 수 없다 |
| 공정 이용을 장담하기 어려움 | 저작권법의 공표 저작물 인용과 공정 이용 규정은 목적, 양, 시장 영향 등을 사안별로 따진다. 책 소개에 쓰는 정도라 괜찮을지 여기서 답할 수 없다. 앱에 유료 요소가 생기면 판단이 불리해질 수 있다 |
| 상표 | Penguin 로고 같은 표시는 저작권과 별도로 상표 문제가 될 수 있다 |
| 추천으로 오해 | 출판사가 힙독을 후원하거나 제휴한 것처럼 보일 수 있다 |
| 지워도 남음 | git 기록, 내려받은 `힙독.html`, 다른 사람의 복제본에는 남을 수 있다 |

위험의 실제 크기는 확인하지 못했다. 표지를 웹에 올린 사례를 다룬 위원회 공식 상담 사례를 이번에 찾지 못했다. 그러므로 "괜찮다"도 "침해다"도 이 문서의 결론이 아니다.

| | 색 표지 (추천) | 공개 도메인 표지 | 출판사 허락 |
|---|---|---|---|
| 방법 | 지금 판본 정보를 끄고 책 제목과 저자만 색 표지로 표시. `Cover.tsx`에 이미 있는 화면 | 니체 생전 초판 표지 등 오래된 판본의 스캔 사용 | 3곳에 각각 사용 범위를 적어 신청 |
| 사용자 만족 | 실제 책 느낌이 줄지만 서고 전체 모양이 통일됨 | 고풍스러운 분위기와 맞음. 독일어 표지라 한국 독자에겐 낯섦 | 가장 높음 |
| 관리자, 제작자 부담 | 거의 없음 | 3종을 찾고 출처별 조건을 확인 | 메일과 회신 관리, 새 책마다 반복. 답이 늦거나 거절될 수 있음 |
| 남는 위험 | 가장 낮음 | 낮음. 단, 스캔 제공 기관의 조건 확인 필요 | 허락 범위 안이면 낮음. 웹앱 공개, 저장소 공개까지 범위에 넣어야 함 |
| 주의 | 책 제목 글자는 앱이 그리는 글꼴 | 해당 스캔이 실제로 있는지 이번에 찾지 않음 | Penguin UK는 [허락 안내](https://www.penguin.co.uk/about/work-with-us/rights-and-permissions/permissions)에서 ISBN, 용도, 크기 등을 요구하고 처리가 늦을 수 있다고 함. 양식이 앱 용도에 맞는지는 문의 필요. 국내 2곳의 절차는 미확인 |

**추천 이유:** 판단 기준인 "관리자가 덜 누르는 쪽"에 가장 맞고, 지금 바로 끝난다. 다른 책과 같은 모양이라 사용자가 등록한 책과도 어울린다. 실제 표지의 매력이 꼭 필요하다는 사용자 반응이 나오면 그때 출판사 허락으로 넘어간다.

## 소유자가 정할 것

1. 표지 방식: 색 표지(추천), 공개 도메인, 출판사 허락 중 무엇으로 할지
2. 이미 공개된 표지: 앞으로만 뺄지, git 기록까지 지울지. 기록을 지우는 일은 되돌리기 어렵고 다른 복제본은 지우지 못한다. 먼저 전문가에게 물어볼 만한 항목이다
3. 유료 기능 계획: 있으면 상담할 때 함께 알린다
